# Coss UI components

Official Coss UI registry source, retrieved September 14, 2026 from https://github.com/cosscom/coss/tree/main/apps/ui/public/r. Local changes initially only remap registry imports to application aliases.

Components are composed in the Focus application; their behavior and design tokens come from Coss UI and Base UI. Use the configured @coss registry for future additions.
